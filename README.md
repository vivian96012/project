# 東協廣場：跨過一道門，看見一座城 ｜ 專題網頁

> **《新中城．城中心》影展企劃「東協不邪」**：透過探險喜劇影片與實地田野調查，翻轉大眾對台中東協廣場的刻板印象，探索全臺最完整的東南亞微型生活圈與異國美食。

---

## 📄 專案簡介 (Project Overview)
本專案為大學數位行銷程式設計課程之期末/期中專題成果網頁。網頁內容聚焦於台中舊城區再生、東協廣場的多元文化共融，以及平替微旅行的高 CP 值體驗。透過語意化 HTML5 與自適應 CSS 樣式，提供使用者流暢的響應式閱讀體驗。

- **場域地點**：台中市中區綠川西街 135 號（東協廣場）
- **專題主題**：多元文化共融、異國平替旅遊、舊城商圈振興
- **整理日期**：2026 年 11 月 5 日
